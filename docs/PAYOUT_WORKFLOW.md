# Creator payout workflow

1. Creator reaches eligibility requirements.
2. Creator completes required payout/identity/tax onboarding.
3. Server records eligible earning events.
4. Payout request is created.
5. Risk/compliance checks run.
6. Payment provider processes payout.
7. Verified webhook updates payout state.
8. Reconciliation records provider reference and final status.

Never let the mobile client directly set balance, payout status or provider references.
